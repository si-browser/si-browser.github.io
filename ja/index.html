Android の WhatsApp Web についてのよくある質問

Android で WhatsApp Web の複数アカウントを使うには？

Google Play 版 SiBrowser の Web Scanner を開き、アカウントスペースを選びます。WhatsApp Web が提供する QR コードまたは電話番号の方法でアカウントをリンクし、ログイン済みのスペースを切り替えて使えます。

アカウントスペースはいくつ使えますか？

標準で2つのスペースが含まれます。Pro では最大5つのスペースを利用でき、1台の Android 端末でログイン情報を別々に管理できます。

直接ダウンロードする APK にも Web Scanner とゲームは含まれますか？

いいえ。直接配布の APK は別製品の SiMontok ブラウザ版で、Web Scanner と Game Center は含まれません。これらの機能は Google Play から SiBrowser をインストールしてご利用ください。
