Android WhatsApp Web 자주 묻는 질문

Android에서 WhatsApp Web 다중 계정을 어떻게 사용하나요?

Google Play 버전 SiBrowser에서 Web Scanner를 열고 분리된 계정 공간을 선택하세요. WhatsApp Web이 제공하는 QR 코드 또는 전화번호 방식으로 계정을 연결한 뒤 로그인된 공간을 전환할 수 있습니다.

계정 공간은 몇 개까지 사용할 수 있나요?

계정 공간 2개는 무료입니다. 버전 1.0.48부터 호환되는 Android System WebView에서 Pro로 공간을 추가할 수 있습니다. Web Scanner에는 Android 9 이상이 필요합니다. 실제 사용 가능한 수와 동시 접속은 기기 및 WhatsApp Web에 따라 달라지며 상시 접속은 보장되지 않습니다.

직접 다운로드하는 APK에도 Web Scanner와 게임이 포함되나요?

아니요. 직접 배포하는 APK는 별도 제품인 SiMontok 브라우저 버전으로 Web Scanner와 Game Center가 포함되지 않습니다. 해당 기능은 Google Play에서 SiBrowser를 설치해 이용하세요.
